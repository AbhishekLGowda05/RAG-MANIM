## CONTEXT: What is Theta?

Theta (θ) is a numerical score representing a learner's ability level.
- Range: typically -3.0 to +3.0
- θ < -1.0 → weak learner
- -1.0 ≤ θ < 0.0 → below average
- 0.0 ≤ θ < 0.5 → average
- 0.5 ≤ θ < 1.0 → above average
- θ ≥ 1.0 → strong learner

Theta is estimated by giving the user adaptive diagnostic questions 
and updating the estimate after each answer. In real IRT, this uses 
Maximum A Posteriori inference. We are SIMULATING this on the frontend.

### STEP 2 — Theta Estimation Algorithm (Frontend Simulation)

After ALL 7 questions are answered, compute theta using this 
simplified simulation of MAP IRT estimation:

```javascript
function estimateTheta(responses) {
  // responses = array of { correct: boolean, b: number }
  // b values: [-1.5, -1.0, -0.5, 0.0, 0.5, 1.0, 1.5]
  // discrimination parameter a = 1.0 for all items (fixed)
  
  let theta = 0.0; // prior mean
  const a = 1.0;   // discrimination (fixed)
  
  // Run 50 gradient ascent iterations (MAP estimation simulation)
  for (let iter = 0; iter < 50; iter++) {
    let gradient = -theta / 1.0; // prior gradient (N(0,1))
    
    for (const { correct, b } of responses) {
      // 2PL probability
      const P = 1 / (1 + Math.exp(-a * (theta - b)));
      // Gradient contribution
      gradient += correct ? a * (1 - P) : -a * P;
    }
    
    theta += 0.1 * gradient; // learning rate 0.1
    
    // Clamp to [-3, 3]
    theta = Math.max(-3.0, Math.min(3.0, theta));
  }
  
  return Math.round(theta * 100) / 100; // round to 2 decimal places
}
```
